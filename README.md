# Telegram Poll Bot / Телеграм‑бот для голосований

Бот предназначен для создания простых голосований в Telegram с записью участников в **основной список** и **резерв**. Типичный сценарий использования — запись на тренировку или мероприятие с ограниченным количеством мест.

Бот написан на `python-telegram-bot` и использует **PostgreSQL** для постоянного хранения данных.

---

## Фактическая функциональность

На текущий момент бот реализует **следующий набор возможностей**:

- ✅ Создание голосования по команде `/create`
- 📝 Название голосования вводится пользователем
- 🗳 Два фиксированных варианта ответа:
  - **«Иду»** — участие
  - **«Пропущу»** — отказ
- 👥 Автоматическое формирование списков:
  - **Основной состав** — первые `N` пользователей, выбравших «Иду»
  - **Запас** — все последующие пользователи, выбравшие «Иду»
- 🔄 Автоматическое обновление сообщения при каждом голосе
- ⏱ Сортировка участников по времени голосования (кто проголосовал раньше — выше)
- 📬 Личное уведомление пользователю, который: 
  - находился в резерве и был автоматически перемещён в основной состав
- 🗄 Постоянное хранение данных в PostgreSQL:
  - голосования
  - голоса пользователей
  - время голосования

---

## Ограничения и важные особенности

- ❗ Количество мест **не вводится при создании голосования**
  - лимит основного состава задаётся **через переменную окружения** `MAIN_PLAYERS_LIMIT`
- ❗ Названия вариантов ответа **не настраиваются**
- ❗ Голосование нельзя закрыть или удалить через команды
- ❗ Бот **не может писать пользователю первым**, если тот не взаимодействовал с ботом ранее
  - в этом случае уведомление о переводе из резерва в основной состав может не дойти
- ❗ Кнопки корректно работают **только в исходном сообщении**
  - пересылка сообщения в другие чаты не поддерживается

## Формат сообщения с голосованием

```
📊 Название голосования

✅ Иду
1. Имя Участника 1
2. Имя Участника 2
...

🔄 Запас
• Имя Участника N+1
• Имя Участника N+2

❌ Пропущу
• Имя Участника X
• Имя Участника Y
```

---

## Команды бота

- `/start` — приветственное сообщение
- `/help` — краткая инструкция
- `/create` — создать новое голосование
- `/cancel` — отменить создание голосования (на этапе ввода названия)

---

## Переменные окружения

Бот **обязательно** требует следующие переменные окружения:

```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
DATABASE_URL=postgresql://user:password@host:5432/dbname
MAIN_PLAYERS_LIMIT=12
```

- `MAIN_PLAYERS_LIMIT` — максимальное количество участников в основном списке
  - если не задано, используется значение `12`

---

## Хранение данных

Используется PostgreSQL (через `asyncpg`).

Создаются следующие таблицы:

- `polls` — информация о голосованиях
- `poll_votes` — голоса пользователей с timestamp
- `user_states` — состояние диалога при создании голосования

⚠️ Данные **не теряются** при перезапуске бота.

## Запуск

### Локально

```bash
python bot.py
```

или

```bash
python3 bot.py
```

### Docker

Проект предполагает запуск через `docker-compose` (PostgreSQL + бот).

## Что бот **не делает** (на данный момент)

- выбор количества мест при создании голосования
- произвольные варианты ответов
- закрытие / завершение голосования
- админ‑управление голосованиями
- несколько типов голосований
- web‑интерфейс
