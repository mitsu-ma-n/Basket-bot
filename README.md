# Telegram Poll Bot / Телеграм Бот для Голосований

Telegram-бот для создания голосований с ограниченным количеством мест и системой резервных участников.

## Возможности

- ✅ Создание голосований с двумя вариантами ответа
- 📊 Ограничение количества основных участников
- 🔄 Автоматическое управление резервными участниками
- 📤 Возможность пересылки голосований в другие чаты
- 🔄 Изменение голосов в реальном времени
- 👥 Отображение имен участников

## Установка

### 1. Клонируйте репозиторий или создайте папку с файлами

```bash
git clone <repository_url>
cd Basket-bot
```

### 2. Установите Python

Убедитесь, что у вас установлен Python 3.7 или выше:

```bash
python --version
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Создайте бота в Telegram

1. Найдите бота [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен бота
4. Сохраните токен для следующего шага

### 5. Настройте переменные окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Откройте `.env` и вставьте токен вашего бота:

```
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
```

## Запуск бота

### Windows

```bash
python bot.py
```

### Linux/Mac

```bash
python3 bot.py
```

Или сделайте файл исполняемым:

```bash
chmod +x bot.py
./bot.py
```

## Использование

### Команды бота

- `/start` - Начать работу с ботом
- `/create` - Создать новое голосование
- `/help` - Показать справку
- `/cancel` - Отменить создание голосования (во время создания)

### Создание голосования

1. Отправьте команду `/create`
2. Введите название голосования
3. Введите количество основных мест (число)
4. Введите название первого варианта (положительный ответ)
5. Введите название второго варианта (отрицательный ответ)

### Формат сообщения с голосованием

```
📊 Название голосования

✅ Первый вариант
1. Имя Участника 1
2. Имя Участника 2
3. Имя Участника 3

🔄 Запас
• Имя Участника 4
• Имя Участника 5

❌ Второй вариант
• Имя Участника 6
• Имя Участника 7
```

### Как работает система резерва

- **Основные места**: Первые N участников (где N - число, указанное при создании)
- **Резерв**: Все последующие участники, проголосовавшие за первый вариант
- Участники в резерве добавляются в порядке голосования

### Пересылка голосований

После создания голосование можно переслать в любой чат или группу. Кнопки будут работать везде, где переслано сообщение.

### Зависимости

- `python-telegram-bot` v20.7 - Библиотека для работы с Telegram Bot API

### Хранение данных

Голосования хранятся в памяти (словарь `polls`). При перезапуске бота все голосования будут утеряны. Для продакшн-использования рекомендуется добавить базу данных (SQLite, PostgreSQL и т.д.).

## Устранение неполадок

### Бот не запускается

- Проверьте, правильно ли указан токен в `.env`
- Убедитесь, что установлена нужная версия `python-telegram-bot`
- Проверьте подключение к интернету

### Голосования не сохраняются

Это нормально - голосования хранятся в памяти. При перезапуске бот начинает с чистого листа.

### Кнопки не работают после пересылки

Убедитесь, что бот запущен. Кнопки работают только пока бот активен.
